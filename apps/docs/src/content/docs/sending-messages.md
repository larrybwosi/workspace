# Sending & Managing Messages

Communication is the core of Scrymechat. This guide covers how to send messages, format text, upload attachments, react with emojis, initiate threads, and use keyboard shortcuts for maximum productivity.

---

## 1. Channels vs. Direct Messages (DMs)

Scrymechat organizes discussions into **Channels** and **Direct Messages**:

- **Public Channels (`#`)**: Open for all workspace members to browse, join, and post.
- **Private Channels (`🔒`)**: Restricted to specific members invited by channel owners.
- **Direct Messages (DMs)**: Private 1-on-1 or small group conversations outside of channels.

> INFO: Keyboard Shortcut: Press `Ctrl + K` (Windows/Linux) or `Cmd + K` (macOS) to launch the Global Command Palette and jump to any channel or DM instantly!

---

## 2. Composing & Formatting Messages

The message editor supports full Markdown syntax, code blocks, syntax highlighting, and emoji pickers.

### Basic Formatting Syntax

| Style | Syntax | Result |
| :--- | :--- | :--- |
| **Bold** | `**bold text**` | **bold text** |
| *Italics* | `*italic text*` | *italic text* |
| ~~Strikethrough~~ | `~~strikethrough~~` | ~~strikethrough~~ |
| `Inline Code` | `` `code` `` | `code` |
| Code Block | ` ```ts const x = 1; ``` ` | Formatted code block with syntax highlighting |

### Mentions & Notifications

- `@username`: Notifies a specific user and sends a direct mention alert.
- `@channel` / `@here`: Notifies all active members in the channel.

> WARNING: Use `@channel` judiciously in large workspaces to avoid sending excessive notifications to teammates.

## 3. Message Threads & Reactions

Keep main channel discussions clean and organized by starting threaded replies.

### Starting a Thread

1. Hover over any message in a channel.
2. Click the **Reply in Thread** icon (speech bubble).
3. A right-hand panel opens showing the threaded discussion context.
4. Type your reply and press **Enter**.

### Emoji Reactions

Hover over a message and click the **Add Reaction** icon to pick an emoji (e.g. 👍, 🎉, ❤️, 👀, 🚀). Reactions allow quick acknowledgments without posting extra messages.

---

## 4. File Sharing & Attachments

Share files, screenshots, logs, and documents directly in chat.

1. Drag and drop any file directly into the message editor.
2. Alternatively, click the **+** (Attach) button in the chat toolbar.
3. Add an optional text comment.
4. Press **Enter** to upload and send.

> TIP: Supported file formats include images, videos, PDFs, JSON, logs, and code files. Large images will render with interactive preview modals!

## Message Management Quick Reference

| Action | Shortcut / Method |
| :--- | :--- |
| **Edit Message** | Hover over your message > Click **Edit** (or press `Up Arrow` when editor is empty) |
| **Delete Message** | Hover over your message > Click **More Options (...)** > Select **Delete** |
| **Pin Message** | Hover over message > Click **Pin to Channel** to pin crucial info at the top |
| **Copy Link** | Hover over message > Click **Copy Message Link** to share across channels |
